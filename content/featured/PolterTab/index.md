PolterTab pairs a Chrome extension with an MCP server so an AI agent can drive the Chrome profile you are already signed into, in a window you can watch. It exposes 23 `browser_*` tools for navigation, form fills, shadow-DOM-piercing snapshots and network capture, plus a selector layer that holds up on virtualized pages. Installs in one command and works with any MCP client.
